## ⚠️ CONFIGURACIÓN MANUAL EN PRODUCCIÓN (.env)

NO subir el .env, pero agregar estas líneas manualmente en el servidor:

GOOGLE_CALENDAR_CLIENT_ID=<obtener desde Google Cloud Console - proyecto turnosonlinebb>
GOOGLE_CALENDAR_CLIENT_SECRET=<obtener desde Google Cloud Console - proyecto turnosonlinebb>
GOOGLE_CALENDAR_REDIRECT_URI=https://turnosonlinebb.com/google-calendar/callback
GOOGLE_CALENDAR_TEST_TOKEN=<generar un token aleatorio propio>

## 📋 PASOS PARA SUBIR A PRODUCCIÓN

1. Subir todos los archivos listados arriba
2. Ejecutar migraciones:
   php artisan migrate
3. Actualizar dependencias (si se modificó composer.json):
   composer install --no-dev --optimize-autoloader
4. Limpiar cache:
   php artisan config:clear
   php artisan cache:clear
   php artisan route:clear
   php artisan view:clear
5. Agregar variables de entorno al .env en producción
6. Verificar permisos de archivos si es necesario
